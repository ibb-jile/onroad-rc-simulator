# Onroad RC Simulator – značka / brand assets

## Česky
| Soubor | Co to je |
|---|---|
| `wordmark-dark.svg` | Nápis „Onroad RC“ + proužek + SIMULATOR pro tmavý podklad (průhledné pozadí) |
| `wordmark-light.svg` | Totéž pro světlý podklad |
| `logo-dark.png`, `logo-light.png` | Celé logo s ikonou, průhledné pozadí, šířka 2400 px (tmavá / světlá varianta nápisu) |
| `logo-on-dark.png`, `logo-on-light.png` | Celé logo na plném podkladu `#14181B` / `#F4F2EC` s okrajem |
| `icon-1024.png` | Ikona hry beze změny (1024×1024, průhledný okraj kolem dlaždice) |
| `icon-512.png` | Ikona oříznutá na dlaždici, 512×512 |

Nápis v SVG je převedený na křivky (bez písma, bez rastru, nic se nenačítá zvenku). Ikona je rastrový render, proto je celé logo jen jako PNG.

**Barvy.** Tmavý podklad `#14181B`: nápis `#F4F2EC`, SIMULATOR `#AEB6BC`, proužek `#3CCB5E` / `#F0473F` / `#F2B632`. Světlý podklad `#F4F2EC`: nápis `#14181B`, SIMULATOR `#4A5258`, proužek `#1E8E3E` / `#C41D1B` / `#B37A00`. Ideální stopa: `#E8792B` → `#D9B13B` → `#6DB044`.

**Písmo.** Exo 2 (SIL Open Font License 1.1): „Onroad RC“ řez 800 italic, SIMULATOR řez 500 (tmavý podklad) / 600 (světlý), prostrkání 0,34 em. Soubor písma v repozitáři není.

## English
| File | What it is |
|---|---|
| `wordmark-dark.svg` | "Onroad RC" + stripe + SIMULATOR for dark backgrounds (transparent) |
| `wordmark-light.svg` | Same for light backgrounds |
| `logo-dark.png`, `logo-light.png` | Full logo with icon, transparent, 2400 px wide (dark / light wordmark) |
| `logo-on-dark.png`, `logo-on-light.png` | Full logo on a solid `#14181B` / `#F4F2EC` background with margin |
| `icon-1024.png` | Game icon, unchanged (1024×1024, transparent margin around the tile) |
| `icon-512.png` | Icon cropped to the tile, 512×512 |

The SVG wordmarks are converted to outlines (no font, no raster, no external references). The icon is a raster render, so the full logo is PNG only.

**Colours** (hex) are listed in the Czech section above. **Typeface:** Exo 2 (SIL Open Font License 1.1): "Onroad RC" in 800 italic, SIMULATOR in 500 (dark) / 600 (light), letter-spacing 0.34 em. The font file is not included in the repository.
